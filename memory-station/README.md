# 乡村迁徙记忆站

记录家族迁徙路线、人物故事、老宅照片与年代说明的家族记忆站点。

## 功能

**前台（长辈友好：大字号、高对比、字号三档可调）**
- 首页：站点概览 + 家族名录
- 🗺️ 迁徙地图：Leaflet 地图展示各家迁徙路线（虚线+箭头+起讫标记），可按家族筛选，附文字版路线一览
- 📜 岁月时间线：迁徙事件、人物故事按年份排列，自动插入"时代背景"年代说明
- 家族详情：简介、路线、故事、老宅照片（点击可放大）
- 🔒 私密故事：需输入家属告知的访问口令，解锁后本次浏览期间可见该家族全部私密内容
- ✍️ 亲属提交：无需登录，可提交故事/老照片/纠错，进入待审核队列

**管理后台（/admin，默认 admin / admin123）**
- 家庭、迁徙路线（含经纬度）、人物故事、老宅照片、年代说明的增删改查
- 私密故事口令设置；私密照片鉴权访问
- 亲属提交审核：通过后自动收录为正式故事/照片
- 修改密码

## 运行

```bash
npm install
npm run seed   # 首次：写入示例数据（可选）
npm start      # http://localhost:3000
```

- 数据库：`data/memory.db`（SQLite，sql.js WASM 实现，无需编译）
- 上传照片：`data/uploads/`
- 端口：环境变量 `PORT`，默认 3000

## 目录结构

```
server.js          Express 服务与全部 API
db.js              sql.js 数据库封装
seed.js            示例数据 + 怀旧风格占位照片生成
public/            前台页面（index/map/timeline/family/story/submit）
public/admin/      管理后台单页应用
public/lib/leaflet 本地化 Leaflet（地图瓦片加载失败时路线仍可见）
data/              数据库与上传文件
```

## 说明

- 私密口令示例：陈氏家族私密故事《奶奶的金戒指》口令 `chen1938`；李氏家族《一张当票》口令 `li1929`
- 首次登录后请立即在后台「修改密码」
